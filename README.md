# ANDY DESIGN — портфолио продуктового дизайнера

Статический сайт-портфолио Андрея Лыкова: главная страница и три подробных кейса
(FlowBot, Online+, Alike). Без фреймворков и сборки — чистый HTML, CSS и JavaScript,
поэтому сайт можно положить на любой хостинг, который умеет отдавать файлы.

## Структура

```
index.html          Главная: hero, статистика, проекты, галерея UI, опыт, контакты
flowbot.html        Кейс FlowBot — редизайн платформы автоматизированного трейдинга
onlineplus.html     Кейс Online+ — соцсеть с крипто-вознаграждением за контент
alike.html          Кейс Alike — приложение для осознанных знакомств
404.html            Страница «не найдено»
css/style.css       Общие стили: токены, шапка, главная, футер, лайтбокс, 404
css/case.css        Стили страниц кейсов
js/main.js          Логика главной: прелоадер, курсор, галерея, таймлайн, лайтбокс
js/case.js          Логика кейсов: навигация по разделам, «до/после», видео, лайтбокс
js/transition.js    Анимированный переход между страницами
assets/img/         Изображения главной страницы
assets/cases/       Изображения и видео кейсов
```

## Запуск локально

Сайту не нужна сборка, но открывать файлы через `file://` не стоит: часть браузерных
API работает только по HTTP. Поднимите любой локальный сервер из корня проекта.

```bash
python3 -m http.server 43127
```

Затем откройте http://127.0.0.1:43127

Альтернатива, если установлен Node.js:

```bash
npx serve .
```

## Публикация

Сайт статический, поэтому подойдёт любой из вариантов.

### Vercel или Netlify

Подключите репозиторий, сборку указывать не нужно: команда сборки пустая,
каталог публикации — корень проекта. Домен добавляется в настройках проекта,
дальше остаётся прописать у регистратора DNS-записи, которые покажет панель.

### Обычный хостинг (FTP, cPanel)

Загрузите содержимое репозитория в корневой каталог сайта (обычно `public_html`).
Никаких дополнительных настроек не требуется, кроме страницы ошибок: для Apache
добавьте в `.htaccess` строку `ErrorDocument 404 /404.html`.

## Поддержка контента

- Проекты на главной — блок `.stack` в `index.html`: одна карточка `article.card` на проект.
- Галерея UI — блок `.hscroll__track`: одна `figure.shot` на изображение. Счётчик
  `01 / 04` в разметке нужно обновить вручную под новое количество.
- Опыт — блоки `details.job` в `index.html`, порядок сверху вниз от свежего к старому.
- Кейсы — страницы `flowbot.html`, `onlineplus.html`, `alike.html`. Раздел кейса
  попадает в навигационную панель, если у секции есть атрибут `data-rail="Название"`.
- Изображение, которое должно открываться на весь экран, помечается атрибутом `data-zoom`.
